# ECG ACLS Master Lab

Simulador educativo de ECG, ritmos cardíacos y protocolos ACLS/ERC.

Este repositorio genera automáticamente, con GitHub Actions:

- **APK de Android** (artefacto `APK-Android`)
- **Instalador y versión portátil para Windows** (artefacto `Instalador-Windows`)

Los archivos aparecen en **Actions → (última ejecución) → Artifacts**, o en **Releases** si publicas una versión con una etiqueta `v1.0.0`.

La app es una sola página (`www/index.html`) y funciona sin internet.

> Herramienta educativa. No reemplaza las guías vigentes AHA/ERC ni el juicio clínico.
